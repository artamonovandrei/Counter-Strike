# assets/

Everything in this directory is generated by code in `backend/app/scripts/`. Nothing here
was imported from anywhere, and there are no binary files — no meshes, no textures, no
audio samples. That is deliberate: it removes every licensing question, keeps the repo
small, and means the map diffs cleanly in git.

## Files

| File | Generated by | What it is |
| --- | --- | --- |
| `maps/alley.json` | `python -m app.scripts.gen_map` | Level geometry, spawns, materials, lights |
| `maps/alley.nav.json` | `python -m app.scripts.gen_nav alley` | Waypoint graph for bot pathfinding |

Regenerate both with `make assets` from the repo root.

## Map format

```jsonc
{
  "name": "alley",
  "version": 1,
  "bounds": [minX, minY, minZ, maxX, maxY, maxZ],
  "ambient": "#404652",
  "sky": ["#bottom", "#top"],
  "fog": { "color": "#2a323d", "near": 40, "far": 110 },
  "materials": { "wall": { "color": "#6a6257", "roughness": 0.9, "metalness": 0.02 } },
  "boxes": [
    { "p": [cx, cy, cz], "s": [sizeX, sizeY, sizeZ], "m": "wall" }
  ],
  "spawns": { "A": [{ "p": [x, y, z], "yaw": 3.1416 }], "B": [] },
  "lights": [{ "p": [x, y, z], "color": "#fff2d8", "intensity": 1.1, "distance": 60 }]
}
```

Boxes are axis-aligned and defined by **centre + full size** (not min/max — a common
source of off-by-half bugs when editing by hand). The same array drives the server's
collision world and the client's Three.js instanced meshes, so there is no way for what
you see to differ from what the server shoots at.

Coordinates are metres, Y is up, and yaw 0 faces −Z (Three.js convention). Team A spawns
at −Z looking toward +Z; team B is the mirror.

## Nav format

```jsonc
{
  "map": "alley",
  "nodes": [{ "id": 0, "p": [x, y, z], "cover": 0.42 }],
  "links": [[1, 7, 8]]   // links[i] = neighbour ids of node i
}
```

`cover` is the fraction of horizontal directions blocked within 3.5 m — 0 is open ground,
1 is a corner. Bots use it to pick somewhere sensible to retreat to.

`gen_nav.py` keeps only the largest connected component. An isolated pocket (a node on top
of a crate that nothing links to) would trap any bot that pathed into it.

## Colours

`materials[*].color` is the surface albedo, used as-is. The client multiplies it by a
near-white generated detail texture (grain, mortar, plank shadows), so what you write here
is roughly what you see — a colour at 0.6 luminance renders at about 0.52.

Keep them in the mid-to-light range. There is no global illumination, so anything the sun
does not reach is lit only by the `ambient` and hemisphere terms, and dark scenery hides
players far more effectively than it looks like it will.

Verify with `frontend/tools/texture-luminance.ts` (see the README) after changing them.

## Audio

There isn't any, as data. Every sound is synthesised at runtime by
`frontend/src/audio.ts` using WebAudio oscillators and generated noise buffers — a
gunshot is a filtered noise crack, a pitch-swept sine for body, and a decaying tail.
Nothing to license, nothing to attribute, nothing to download.

## Making your own map

1. Copy `gen_map.py`, edit `build()`, change `MAP_NAME`.
2. Run it, then run `gen_nav.py <name>`.
3. Set `MAP_NAME=<name>` in `.env`.

Keep brush counts in the low hundreds. The renderer batches by material, so the cost is
driven by distinct materials rather than brush count, but the server's collision
broadphase does scale with brushes per grid cell.
